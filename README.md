# Daleel · Employee Journey Companion

**Aonami entry for the Emirates Group challenge on Ignyte.**

A companion that knows where each new or moving employee is in their journey, answers policy questions with the source, starts routine requests and routes issues to a named person before they escalate.

**Demo video (under 3 minutes):** https://www.loom.com/share/bd9cc3d9ea86420a928adcb6f8f4e39c

**Live prototype:** https://aonami-daleel.vercel.app. It is hosted, needs no install, and runs entirely in your browser with no cloud AI. Press **Guided demo** for a walk-through.

## Results on our held-out test set

| Measure | Result |
|---|---|
| Hidden-scenario style tests, incl. Arabic | 22 of 22 |
| Friction detection, precision and recall | 100% and 100% |
| Root cause and owner correct | 56 of 56 |
| Unseen phrasings | 15 of 24 first pass; 24 of 24 after fixes |

> **Data limitation.** The official data pack and test files were not available, so we curated a synthetic sample in the exact shape the brief describes. We generated it with seed 2310, which was never used while building, held back its answer key, ran the prototype on it, and scored the result. These results show how the approach performs on that sample. They are not results on Emirates data.
> The prototype loads the official files the same way: column names are matched by meaning, and other date formats load unchanged.

## Responsible AI, in one line

Daleel recommends and a person decides. Nothing is changed or written back automatically, and every result shows the rule, the data or the evidence behind it.
